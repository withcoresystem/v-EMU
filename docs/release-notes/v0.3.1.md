# v-EMU 0.3.1

**Small UI and documentation patch on the 0.3.0 broad fork base.**

v-EMU 0.3.1 does not change VM, storage, network, seamless or 3D behaviour. It
shortens the Delete VM dialog and documents the cleanup rules that were already
implemented.

## Changes

- **Delete VM dialog:** now short and context-aware. It adds the forced-off
  warning only for a running VM and explains only the two choices:
  **Delete VM only** keeps the disk chain and recovery files; **Delete VM and
  disks** removes managed disks and recovery files.
- **In-app Guide:** documents that deleting a seamless/3D VM removes shortcuts
  either way, keeps recovery state only with **Delete VM only**, and does not
  restore host `qemu.conf` automatically.
- **Packaging:** the `.run` payload is rebuilt with the updated dialog, guide
  and release notes.

## Validation

- Full suite: **991 tests** (47 subtests).
- Version bump and `.run` build verified on the public tree.
- Host install/upgrade path remains the 0.3.0 `--standard` flow.

## Upgrade notes

Re-run the 0.3.1 `.run` or `./setup.sh --standard` to update the CLI, UI and
daemon. The guest/VM data, storage and network configuration are untouched.
